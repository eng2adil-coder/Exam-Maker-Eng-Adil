طريقة رفع التطبيق مجاناً على GitHub Pages

  1. سجّل الدخول إلى حسابك في موقع github.com ثم اضغط على زر New لإنشاء مستودع جديد (Repository) باسم مثل exam-maker واجعله عاماً (Public).
  2. داخل المستودع، اضغط على Add file ثم Create new file (أو Upload files).
  3. سمِّ الملف index.html والصق فيه كود هذا التطبيق بالكامل، ثم اضغط Commit changes.
  4. اذهب إلى تبويب Settings ثم من القائمة الجانبية اختر Pages.
  5. تحت خيار Branch اختر main ثم اضغط Save.
  6. بعد دقيقة واحدة سيظهر لك رابط تطبيقك المباشر (مثل username.github.io/exam-maker) ويمكنك فتحه من الهاتف أو الحاسوب ومشاركته مع الزملاء!
